# White Eagles & Co. — Official Website

Repository for **White Eagles & Co. s.r.o.**, a Slovak web development and
digital marketing company based in Bratislava.

![White Eagles](public/assets/logo-blue.png)

## Services

- **Web development** — custom sites (React, PHP, Python) and WordPress
- **Bug fixing** — technical support and optimisation for existing sites
- **PPC advertising** — Google Ads and Meta Ads
- **Web analytics** — GA4, Google Tag Manager, server-side tracking
- **Automation bots** — Python bots for lead handling and Bazoš auto-posting
- **Compliance** — cookie banners with Google Consent Mode v2

## Tech stack

- **Framework**: [Next.js 16](https://nextjs.org/) App Router, built as a static
  export (`output: "export"`, `trailingSlash: true`, output in `dist/`)
- **Language**: TypeScript, React 19
- **Styling**: hand-written CSS with custom properties, no UI framework
- **Localisation**: [next-intl](https://next-intl.dev/) — Slovak, Russian,
  English, with `localePrefix: "always"`
- **Content**: Markdown blog posts in `src/content/blog/<locale>/`
- **Backend API**: a PHP endpoint for form handling
- **Integrations**: Mailgun for email, Telegram for instant notifications,
  Google reCAPTCHA v3 for spam protection

## Repository structure

```
src/
  app/[locale]/     route segments: home, services, blog, legal pages
  app/not-found.tsx trilingual 404, served by nginx for any missing path
  components/       reusable UI, including the JSON-LD graph
  content/blog/     Markdown articles per locale
  data/             services and portfolio definitions
  i18n/             next-intl routing and request config
  messages/         translation files (sk, ru, en)
  styles/           global tokens
public/
  api/              PHP scripts (send-mail.php)
  llms.txt          machine-readable company summary
  sitemap.xml       generated by generate_sitemap.js
```

## Commands

```bash
npm run dev     # dev server on port 3010
npm run build   # generates the sitemap, then a static export into dist/
npm run lint
```

`npm run build` runs `generate_sitemap.js` first — it is the single source of
`public/sitemap.xml`.

## Routing

The site is served by nginx from the static export. The Slovak version is
served in place at the domain root; visitors whose browser language is Russian
or English are redirected to `/ru/` or `/en/`. Missing paths return a real 404.

The English blog is served with `noindex` — see `SEO-STRATEGY.md`.

## Indexing

```bash
node submit_to_google.js    # submits the sitemap to Search Console, then IndexNow
node submit_to_indexnow.js  # IndexNow only (Bing, Seznam, Yandex)
```

Both read a service account key; override the path with `GOOGLE_KEY_FILE`.
