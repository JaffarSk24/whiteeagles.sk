# whiteeagles.sk — аудит и стратегия роста без рекламного бюджета

**Дата:** 3 августа 2026
**Цель:** **монополизировать русскоязычный сегмент Словакии** — стать подрядчиком по умолчанию для каждого русскоязычного предпринимателя в стране, которому нужен сайт. Без платной рекламы.
**Позиция:** вы говорите со мной по-русски — ваш сайт работает на словацком рынке.

## 0. Главный вывод за 30 секунд

**Сайт не «просел в выдаче». Он структурно невидим для Google.**

За 14 дней настоящий Googlebot (проверено по IP-диапазону `66.249.*`) сделал по всем страницам сайта **порядка 40 запросов**. Из них самая посещаемая роботом страница — `https://whiteeagles.sk/` (35 обращений), которая отдаёт **пустую страницу ошибки Next.js с HTTP 200** и без единого слова контента.

То есть: главная точка входа домена — куда идут прямые заходы, брендовые запросы и все внешние ссылки — для Google выглядит как сломанная пустая страница, которая при этом рапортует «всё в порядке, 200 OK».

Пока это не исправлено, любая работа над контентом и ссылками бессмысленна: Google просто не тратит краулинговый бюджет на домен, который в корне отдаёт мусор.

Хорошая новость: **производительность и разметка у сайта в порядке** (TTFB ~150 мс, gzip, статический экспорт, честный SSR, богатый JSON-LD, hreflang, sitemap). Сломано именно то, что чинится за один день.

И главное: **русскоязычная ниша в Словакии сейчас никем не занята.** Всю выдачу держат офшорные студии из Беларуси и Украины — ни одного словацкого s.r.o. Сегмент маленький, и именно поэтому его реально закрыть целиком силами одного человека за 6–9 месяцев. Тот, кто закроет его первым, закроет надолго. Подробно — раздел 4.

## 2. Критические технические поломки

### 2.1. Корень домена отдаёт страницу ошибки (блокер №1)

```
$ curl -I https://whiteeagles.sk/
HTTP/1.1 200 OK
Content-Length: 4969
```

Тело ответа:

```html
<html id="__next_error__">...404: This page could not be found...
...digest":"NEXT_REDIRECT;replace;/sk;307;"
```

Что происходит: при статическом экспорте `redirect()` из серверного компонента не превращается в HTTP-редирект — он «запекается» в RSC-payload. Nginx отдаёт статический `index.html`, в котором нет ни `<title>`, ни `<meta http-equiv="refresh">`, ни заголовка `Location`. Браузер с JS доедет до `/sk/`. Краулер видит пустую 200-страницу.

**Последствия:** вес всех внешних ссылок и брендовых заходов упирается в тупик; Google снижает частоту обхода всего домена.

**Фикс:** серверный `301` на уровне nginx (см. 2.5). Одна строка.

---

### 2.2. Любая несуществующая страница отдаёт 200 (блокер №2)

```
$ curl -o /dev/null -w "%{http_code}" https://whiteeagles.sk/ru/nonexistent-page-test/
200
```

Причина — в nginx:

```nginx
location / {
    try_files $uri $uri/ /index.html;   # ← фолбэк на сломанный index.html с кодом 200
}
```

Каждый битый URL, каждая ссылка с опечаткой, каждый URL из сканеров-ботов возвращает `200 OK` с той же пустой страницей ошибки. Для Google это **soft 404** — один из сильнейших негативных сигналов качества на уровне всего домена. Индекс засоряется бесконечным числом «страниц» с идентичным пустым содержимым.

В логах видно, как боты долбятся в `/wp-config.php`, `/.env`, `/.git/config`, `/.aws/credentials` — **и всё это получает 200 OK**.

### 2.3. Четыре копии сайта вместо одной

```
http://whiteeagles.sk/       → 200 (нет редиректа на HTTPS)
https://www.whiteeagles.sk/  → 200 (нет редиректа на без-www)
https://www.whiteeagles.sk/ru/ → 200
https://whiteeagles.sk/ru/   → 200
```

В конфиге nginx `server_name whiteeagles.sk www.whiteeagles.sk;` в обоих блоках, `listen 80` без редиректа. Каждая страница существует в 4 вариантах. Canonical-теги частично спасают, но сигналы всё равно размазываются, а HTTP-версия — ещё и минус к доверию.

### 2.4. Разметка отзывов без отзывов — риск ручных санкций

В JSON-LD на каждой странице:

```json
"aggregateRating": {"ratingValue": "4.9", "reviewCount": "24"}
```

Это self-serving review markup на `Organization` и `ProfessionalService`. Google явно запрещает такую разметку для собственной организации без реальных, проверяемых отзывов на странице. В лучшем случае игнорируется, в худшем — ручные меры за спам структурированными данными. **Убрать до появления настоящих отзывов** (а настоящие лучше собирать в Google Business Profile — см. 5.2).

### 2.5. Готовый патч nginx

```nginx
# 1. HTTP → HTTPS, всё на один хост
server {
    listen 80 default_server;
    server_name whiteeagles.sk www.whiteeagles.sk;
    return 301 https://whiteeagles.sk$request_uri;
}

# 2. www → без www
server {
    listen 443 ssl;
    server_name www.whiteeagles.sk;
    ssl_certificate     /etc/letsencrypt/live/whiteeagles.sk/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/whiteeagles.sk/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;
    return 301 https://whiteeagles.sk$request_uri;
}

# 3. Основной хост
server {
    listen 443 ssl;
    server_name whiteeagles.sk;
    root /var/www/html;
    index index.html;

    ssl_certificate     /etc/letsencrypt/live/whiteeagles.sk/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/whiteeagles.sk/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    # КЛЮЧЕВОЕ: корень отдаёт настоящий 301, а не пустую страницу
    location = / {
        return 301 https://whiteeagles.sk/sk/;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|webp|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, no-transform";
        access_log off;
    }

    # КЛЮЧЕВОЕ: убран фолбэк на index.html → честный 404
    location / {
        try_files $uri $uri/ $uri.html =404;
    }

    error_page 404 /404.html;
    location = /404.html { internal; }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }
}
```

Проверка перед применением: `nginx -t && systemctl reload nginx`.

> **Нюанс автоопределения языка.** Сейчас `/` пытается угадать язык браузера на клиенте. С серверным 301 на `/sk/` это уходит. Правильный компромисс: `301 → /sk/` (словацкий как основной рынок и `x-default`), а переключатель языков в шапке остаётся. Если хочется сохранить автоопределение — делать его через nginx `map $http_accept_language` с кодом 302, но для SEO стабильный 301 надёжнее.

### 2.7. Аналитика, скорее всего, не считает конверсии

В коде события уходят **только в `dataLayer`**:

```ts
// src/utils/analytics.ts
window.dataLayer.push({ event: eventName, ...params });
```

При этом GA4 подключён **напрямую через gtag.js** (`G-31E4MKB8QX`), параллельно с GTM (`GTM-KK389G5B`). `dataLayer.push` сам по себе в GA4 не попадает — нужны настроенные теги в GTM.

**Что проверить в GTM:**
1. Есть ли триггеры Custom Event на `form_submit`, `order_send`, `contact_click`, `cta_click` и теги GA4 Event, отправляющие их в `G-31E4MKB8QX`. Если нет — **ни одна заявка в GA4 не видна**, и «нулевая конверсия» может быть артефактом замера.
2. Нет ли в GTM ещё одного GA4 Configuration тега на тот же `G-31E4MKB8QX` — тогда просмотры считаются дважды (сайт грузит gtag.js и GTM одновременно).
3. Отметить `order_send` как **ключевое событие (key event)** в GA4 — иначе не будет конверсий в отчётах.

## 3. Контент: почему он не может ранжироваться

Сейчас: **6 статей, переведённых на 3 языка = 18 URL**. Размер русских статей — 2.6–5 КБ markdown, это ~400–800 слов. Последняя публикация — **13 мая 2026**, сайт не обновлялся с 4 июня.

Проблема глубже объёма — в выборе тем. Русские статьи это дословные переводы словацких:

- «Сколько стоит создание сайта в 2026 году?»
- «WordPress или самописный сайт»
- «Как настроить Google Analytics 4»
- «SEO аудит: как проверить свой сайт самостоятельно»

Это **общероссийские инфо-запросы без географической привязки**. По ним конкуренция — весь рунет: Хабр, VC.ru, Тинькофф Журнал, сотни агентств с DR 60+. Сайт с DR ~0 и 40 страницами не займёт по ним ничего. И даже если займёт — трафик придёт из России и Казахстана и никогда не станет заявкой в Словакии.

**Ключевая мысль:** нужно уйти от темы «сайты» к теме «бизнес в Словакии на русском». Русскоязычный предприниматель в Словакии не гуглит «сколько стоит сайт». Он гуглит «как открыть s.r.o. в Словакии», «что такое eKasa», «нужен ли мне DPH», «как принимать оплату картой». Сайт нужен ему **после** — и купит он у того, чью статью прочитал.

## 4. Рынок и цель: монополизировать русскоязычный сегмент

**Решение принято: цель — не доля, а весь сегмент целиком.** Это меняет способ работы, поэтому зафиксируем, что именно из этого следует.

**Аудитория.** Русскоязычных в Словакии — русские, украинцы (включая ~100+ тыс. с временной защитой), белорусы, казахстанцы. Совокупно шестизначное число людей; предпринимателей среди них — на порядки меньше, а ищущих подрядчика на сайт прямо сейчас — единицы запросов в месяц.

Маленький сегмент — это **не аргумент против монополии, а аргумент за неё.** Именно потому, что он маленький, его можно закрыть целиком силами одного человека. В сегменте на 50 тысяч запросов монополия невозможна ни за какие деньги. В сегменте на 200 запросов в месяц — достижима за 6 месяцев без бюджета. И тот, кто закрыл его первым, закрывает его надолго: второму игроку заходить будет уже некуда.

Но «монополия» — это операционно другая задача, чем «хорошее SEO». Различие принципиальное:

| Обычное SEO | Монополия сегмента |
|---|---|
| 10 сильных статей по частотным темам | **Все** темы сегмента, включая запросы с частотой 5/мес |
| Оптимизировать под топ-3 | Занять топ-3 **и** соседние позиции, и блок «Люди также спрашивают» |
| Google | Google + Facebook-группы + Telegram + YouTube + рекомендации + Яндекс |
| Ждать, пока найдут | Быть готовым ответом до того, как начали искать |
| Считать трафик | Считать **долю сегмента**: сколько из всех, кто искал, дошли до тебя |

Ключевой сдвиг в мышлении: при монополии маленького сегмента **глубина важнее охвата**. Не «привести 5000 визитов», а «сделать так, чтобы из 200 человек в Словакии, которым в этом году понадобится сайт на русском, к тебе пришли 150». При среднем чеке от 5000 € даже 5 % конверсии из этих 150 — это результат, ради которого не нужны тысячи визитов.

### 4.1. Кто занимает выдачу сейчас

- `medialine.by`, `slam.by`, `qmedia.by` — Минск
- `web-agent.by` — Беларусь
- `site2u.com.ua` — Украина
- `sitecreative-eu.com`, `cyborg-studio.com` — офшорные студии

**Ни одного словацкого s.r.o.** Все — удалённые подрядчики из другой юрисдикции.

Это и есть позиционный разрыв. Ни `.by`, ни `.ua` студия не выставит словацкую фактуру, не придёт на встречу и не знает, как ведёт себя словацкий покупатель.

### 4.2. Позиционирование, на котором строится всё остальное

Три реальных преимущества, вокруг которых собирается вся семантика, все тексты и все офферы:

**1. Скорость.** 90 % проектов за 15 рабочих дней, средний срок — 10 дней. Офшорная студия с менеджером, ТЗ и часовыми поясами так не может физически. Словацкое агентство — тем более.

**2. Русский язык, удобный заказчику.** Клиент объясняет задачу на родном языке, без перевода и без «я не так понял». Никаких ТЗ на 40 страниц.

**3. Проекты, реально выведенные на словацкий рынок.** 12+ работающих сайтов словацких компаний. Это то, чего нет ни у кого из конкурентов: они делают сайты **для** русскоязычных, но не умеют делать сайты, которые **продают словакам**.

Формулировка позиции, которую нужно повторять везде одинаково — на сайте, в GBP, в подписи, в сообществах:

> **Вы говорите со мной по-русски — ваш сайт работает на словацком рынке.**
> 10 лет в Словакии, 12+ запущенных проектов, 15 дней до релиза, словацкое s.r.o. и фактура.

Именно связка «русский на входе — словацкий рынок на выходе» и есть монополия. Офшорная студия закрывает только левую часть. Словацкое агентство — только правую. Обе половины сразу — больше ни у кого.

**Практический вывод для текстов:** перестать продавать «создание сайтов». Продавать **выход на словацкий рынок**. Заголовок услуги не «Разработка сайтов», а «Сайт, который приводит словацких клиентов — а обсуждаем мы его по-русски».

**Отдельно про бренд:** запрос «White Eagles Bratislava» намертво занят флорбольным клубом FBC White Eagles Bratislava (Instagram, Facebook, FinStat, SZFB). Брендовое SEO по этому имени бесперспективно. В монопольной стратегии узнаваемой единицей должен стать **человек — «Кирилл Мосин»**, а не название компании. Люди в сообществах рекомендуют людей, а не s.r.o.

## 5. Стратегия: пять каналов, ноль бюджета

Порядок важен — каждый следующий опирается на предыдущий. Каналы 1–2 делают тебя видимым, 3 закрывает поиск, 4–5 закрывают всё остальное, где ходит сегмент.

### 5.1. Канал 1 — Технический фундамент (неделя 1)

Без этого остальное не работает. См. раздел 2. Итог недели:

- `/` отдаёт 301
- битые URL отдают 404
- один хост вместо четырёх
- фейковый рейтинг убран
- GSC и GA4 подключены, конверсии считаются

### 5.2. Канал 2 — Google Business Profile (неделя 1–2) ⭐ самый недооценённый

**Это самый мощный бесплатный источник локальных заявок, и его, судя по всему, нет.**

Что даёт GBP:
- попадание в локальный пак (карта + 3 карточки над органикой) по запросам `tvorba web stránok Bratislava`, `webdesign Bratislava` — там, где обычным SEO пробиться нужны годы
- **отзывы**, которые можно легально разметить и показывать (в отличие от текущей фейковой разметки)
- отдельный канал звонков и сообщений, полностью бесплатный
- сущность-подтверждение для Google: адрес в GBP + тот же адрес в JSON-LD + тот же в Firmy.sk = Google понимает, что бизнес реален

Что делать:
1. Создать/подтвердить профиль на **Holíčska 7, Bratislava** (тот же адрес, что в `ProfessionalService`).
2. Категории: `Web designer` (основная), `Marketing agency`, `Software company`.
3. Описание **на словацком**, но с явным упоминанием обслуживания на русском.
4. Атрибуты и услуги: перечислить все 6 услуг с сайта, каждая со ссылкой на свою страницу `/sk/service/*`.
5. **Собрать 8–12 отзывов у существующих клиентов из портфолио** (Biliardovna, Bodabo, Studio Krásy, Top Sklad, Ram Service, Rebuy Stars, Severske Drevo, Slov Uni Sport, Chicago, Moj Servis, Top Kobka, Synchro Žralok). У тебя уже есть 12+ реальных клиентов — это готовый пул. Просить по одному в неделю, не пачкой.
6. Постить в GBP раз в неделю (посты индексируются и держат профиль «живым»).

### 5.3. Канал 3 — Контент: закрыть сегмент исчерпывающе (месяцы 1–6)

Переориентация с «услуг» на «проблемы релоканта, открывающего бизнес».

**Принцип монополии:** цель не «написать хорошие статьи», а **не оставить ни одного вопроса без своего ответа**. Если русскоязычный предприниматель в Словакии что-то гуглит по бизнесу — он должен упереться в твою страницу. Включая запросы с частотой 5 показов в месяц: именно они в сумме и составляют сегмент, и именно их никто не пишет, потому что «невыгодно». Тебе — выгодно, потому что ты берёшь не трафиком, а долей.

**Правила исполнения:**

- В каждой статье — **личный опыт**: «когда я регистрировал s.r.o. в 2016», «мой клиент из Stupavy столкнулся с». Это E-E-A-T, который офшорные студии подделать не могут.
- **FAQ-блок в конце каждой статьи** с разметкой `FAQPage` — так забираются позиции в блоке «Люди также спрашивают», а это ещё один способ занять сегмент шире одной строки выдачи.
- В конце каждой статьи — CTA на бесплатный аудит, но **мягкий и релевантный теме**, а не общий баннер.
- **Перелинковка**: каждая новая статья ссылается на 2–3 старые и на релевантную страницу услуги.
- **Каждый вопрос из сообществ (канал 5) → отдельная статья.** Если человек спросил вслух, значит, десять человек это гуглили молча. Это бесплатный и самый точный источник семантики для сегмента, где обычные инструменты показывают ноль частотности.

### 5.5. Канал 5 — Присутствие в сегменте: сообщества и партнёрская сеть (месяцы 1–6) ⭐ главный рычаг монополии

Поиск закрывает только тех, кто уже ищет. Монополия сегмента — это ещё и те, кто **не ищет, но спросит у знакомых**. В маленьком русскоязычном сообществе рекомендация весит больше, чем позиция в выдаче.

**5.5.1. Сообщества — быть постоянным ответом**

- Facebook-группы «Русские в Словакии», «Украинцы в Словакии», «Наши в Братиславе», группы по релокации и трудоустройству
- Telegram-чаты релокантов и предпринимателей в SK (свой канал `t.me/whiteeaglessk` уже есть)
- Принцип: **не рекламировать, а отвечать.** Человек спрашивает «нужен ли мне cookie-баннер?» — даёшь развёрнутый ответ по существу и ссылку на свою статью. Это одновременно трафик, ссылки, репутация и заявки.
- Цель: **2–3 содержательных ответа в неделю**, стабильно, полгода. Монополия здесь достигается не разовой активностью, а тем, что через 4 месяца твоё имя всплывает в ответах **других людей**. Это и есть момент, когда сегмент закрыт.
- Метрика канала: сколько раз в месяц тебя порекомендовал кто-то, кроме тебя.

**5.5.2. Партнёрская сеть — самый недооценённый рычаг**

Русскоязычного предпринимателя в Словакии уже обслуживают другие русскоязычные специалисты, **которые тебе не конкуренты, а держатели той же аудитории**:

| Партнёр | Почему это работает |
|---|---|
| Русскоязычные бухгалтеры (účtovníctvo) | Ведут десятки s.r.o., знают, у кого нет сайта. Самый ценный партнёр |
| Юристы и агенты по регистрации фирм | Видят клиента ровно в момент открытия бизнеса — до того, как он начал искать сайт |
| Релокационные агентства, визовые консультанты | Первая точка контакта с релокантом |
| Русскоязычные риелторы | Их клиенты часто открывают бизнес следом |
| Переводчики (súdny prekladateľ) | Работают с теми же документами |
| Бизнес-консультанты, налоговые советники | Прямая B2B-аудитория |

Один бухгалтер, ведущий 200 русскоязычных s.r.o., перекрывает по охвату полгода SEO. Схема простая и бесплатная: взаимные рекомендации, взаимные ссылки на сайтах, совместная статья («Открыли s.r.o. — что дальше: бухгалтерия, касса, сайт»), возможно — процент с приведённого клиента.

Цель: **5–8 действующих партнёров за 3 месяца.** Это и есть механизм, который превращает «маленький сегмент» в «сегмент, полностью накрытый одним человеком».

**5.5.3. YouTube / короткие видео (опционально, месяцы 4+)**

Русскоязычного видеоконтента про бизнес в Словакии почти нет. Даже небольшой канал с разборами («открываю s.r.o. — показываю все документы») даёт то, чего не даст текст: лицо, голос, доверие. При монопольной цели это следующий логичный шаг после того, как текстовый сегмент закрыт.

## 7. Чего ожидать (честно)

| Срок | Результат |
|---|---|
| 2–4 недели после фикса технички | Рост обхода Googlebot в 5–10 раз, страницы начинают появляться в GSC |
| 1–2 месяца | GBP даёт первые звонки/сообщения. Это, скорее всего, будет **первый реальный источник заявок** |
| 2–3 месяца | Первые статьи кластера A выходят в топ-10 по русским запросам (конкуренции почти нет — выходят быстро) |
| 3–4 месяца | Партнёрская сеть начинает давать заявки — как правило, раньше и качественнее, чем органика |
| 4–6 месяцев | Стабильные 300–800 визитов/мес органики, 3–8 заявок/мес |
| 6–12 месяцев | Сегмент фактически закрыт: топ по большинству русских запросов + рекомендации от третьих лиц. Словацкие запросы начинают давать дополнительный объём |

**Как мерить монополию, а не трафик.** Обычные метрики (визиты, показы) в маленьком сегменте вводят в заблуждение — 400 визитов в месяц выглядят провалом, хотя могут означать 80 % сегмента. Считать нужно другое:

| Метрика | Где смотреть | Целевое значение к 6 мес. |
|---|---|---|
| Доля русских запросов, где сайт в топ-3 | GSC → Запросы, фильтр по кириллице | **> 70 %** |
| Число русских запросов с любыми показами | GSC | Растёт каждый месяц — значит, охват расширяется |
| Запросы с показами, но **без** своей страницы | GSC | Стремится к нулю — это дыры в монополии |
| Рекомендации от третьих лиц в сообществах | вручную, раз в месяц | ≥ 3 в месяц |
| Активных партнёров | вручную | 5–8 |
| Заявок с прямыми/брендовыми заходами | GA4 | Растёт — признак узнаваемости, а не поиска |

**Один трезвый момент, который стоит держать в голове.** Монополия в русскоязычном сегменте достижима и она правильная цель — но у сегмента есть потолок по объёму. Когда он будет закрыт (реалистично — 6–9 месяцев), рост дальше пойдёт только из словацкого рынка либо из русскоязычных сегментов соседних стран. Это не повод менять план сейчас — это повод не удивиться на седьмом месяце. Русский контент строится первым, потому что там выигрыш быстрый и оборонимый; словацкий подключается параллельно и снимает потолок.
